Teacher photographs go in this folder.

Name each file however you like, then put that file name in the "photo" field
for that person in assets/js/teacher-data.js — for example:

    photo: "teacher-04.jpg"

Square images work best, around 600x600 pixels. JPG or PNG.
If a photo is missing or the file name is wrong, the page falls back to
showing the teacher's number in a circle, so nothing breaks.
