Files hosted on the course site go here — PDFs, slide decks, handouts.

Reference one from a teacher's resources list in assets/js/teacher-data.js,
or from a session in assets/js/day-details.js:

    { label: "Lecture slides, week 8", url: "assets/resources/week8-slides.pdf", kind: "slides" }

kind can be: link, pdf, slides, video, file.

Most teachers will host their own files and give you a URL instead — that is
usually better, because it stays under their control and keeps this repository
small. GitHub blocks any single file over 100 MB and the whole site should
stay under about 1 GB.
